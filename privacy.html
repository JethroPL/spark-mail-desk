Privacy Policy — Spark Mail Desk

Effective date: 10 October 2026

What this app does

Spark Mail Desk is a private tool for Jethro Laungayan's own assistant to manage his personal Gmail accounts (jethro1287@gmail.com and jethro.laungayan@gmail.com). It does not send, reply to, or forward email. Jethro sends everything himself from drafts.

Google scope and what the code does

The app uses the Google scope gmail.modify. The code performs only the following actions on behalf of the account owner:

  • Search and read email messages and threads.
  • Apply or remove labels (including the Gmail "Starred" and "Important" labels).
  • Archive mail from the inbox.
  • Move mail to Trash (or restore from Trash).
  • Create, update, and delete draft messages.

Sending, replying, forwarding, and permanent deletion (beyond Gmail's own 30-day Trash retention) are blocked by code.

Data used and stored

  • Email content is read only for the purpose of displaying it to the account owner through the assistant. The code limits body text to 20 000 characters per message and does not store bodies on disk.
  • Sign-in tokens (Google OAuth refresh tokens) are stored as files on Jethro's own server only, in the secrets/ folder with file permissions set to 600. Only Jethro can read them.
  • An activity log records the action name (e.g. search, trash), the account, and a timestamp. It never stores email content.

No sharing

We do not send, sell, or share any information collected through Spark Mail Desk with any third party.

How to revoke access

Sign in to your Google Account, go to Security > Third-party apps with account access, and remove "Spark Gmail". This revokes the refresh token and the app can no longer access your mailbox.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
